# 1 项目介绍
    本项目实现将多个.bin文件合并生成一个固件包。
       
# 2 使用说明
    本项目主要分为三个部分：HEX文件转为BIN文件、生成固件包、生成固件升级指令
    
    1.HEX文件转为BIN文件：点击"需要转换的Hex文件"后选择要转换的文件，然后点击"保存为Bin文件"即可完成HEX文件转为BIN文件
    
    2.生成固件包        ：点击"需要加密的bin文件"后选择需要加密的bin文件，之后在"文件列表"中会显示刚刚选中的文件的信息
                         包括文件名、文件大小、文件版本号。第一次选择的文件版本号默认为01.0，在"文件列表"中选中文件可以
                         通过右侧的更新按键进行版本号更新，小更新+0.1，最多不超过0.9；大更新小数部分清0，整数部分+1。
                         操作过程中会在"文件列表"中实时显示版本号，同时会在"版本数据.xlsx"中记录更新的版本号。点击"加
                         密并生成固件包"后即可完成固件包的生成，同时会在"固件组成信息.xlsx"记录固件包的信息

    3.生成固件升级指令  ： 之前在文件列表中的信息会复制到"固件包组成"中，在"固件包组成"中选中需要的文件点击"添加"后，该文
                         件就会出现在"需要使用的文件"中。也可以通过"删除"将"需要使用的文件"中的文件去除。通过选择右上角
                         的指令可选择更新类型，然后点击"生成固件指令"完成指令的生成，生成的指令在"固件包升级.txt"显示

## 固件包说明
    1.在0x00的位置写入bin文件个数，然后在后面补0，凑齐32byte（1位bin数量值 + 31位0x00）
    2.MENU表头在0x20位置,APP表头从0x40开始写
    3.数据内容从MenuOffset开始写入，先写入表头数据，再写入app数据。每写完一个bin文件的数据后写入对该数据的校验码，即2字节的CRC，写完CRC即说明这一个文件已经写入完成，然后再下一个扇区开始新的bin文件数据的写入。当所有文件写完后，再在最后写入整个文件的CRC，然后对以上全部数据进行AES——CBC加密。加密完成后对文件进行拆分，每份download_data字节，然后对 每份进行CRC，并把CRC值拼接到每份数据后面，得到多个download_size字节的数据包。然后对多个download_size字节数据包进行合并，生成1个总文件。
      
### 补充
    1.一个扇区大小为512字节
    2.表头信息为TableHeadData[32]=version[4]+DataName[16]+DataStartAddr[4]+DataEndAddr[4]+DataCrc[4]，因为CRC只占两字节的，因此DataCrc前两字节补0，使得表头占32位
    3.修改网络下载速率需要修改download_size的值
    4.修改SD卡程序放的位置需要修改MenuOffset的值

# 4 注意事项
    1.用来加密的.BIN文件需要在同一个文件夹
    2.首次使用建议先删除"版本数据.xlsx"、"固件组成信息.xlsx"、"固件包升级.txt"，以免数据产生干扰
    3.打开excel时无法对数据进行保存，数据保存时需要关闭excel
    4."固件包升级.txt"最好以记事本打开，不然数据可能显示不全
    5.用来加密的.BIN文件要带上时间前缀(yyMMddHHmm)
